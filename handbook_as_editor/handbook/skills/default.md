# Skills por Defecto

Considerar siempre en cualquier tarea:

- `estructura-narrativa` — ¿La forma del libro es sólida?
- `arcos-de-personaje` — ¿Los personajes se están ganando lo que les ocurre?
- `integracion-de-escenas` — ¿Cada escena (especialmente las explícitas) sirve al conjunto?

Cargar skills adicionales solo cuando la tarea específica lo requiera.

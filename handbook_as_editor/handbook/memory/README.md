# Memoria

Las decisiones estables sobre el libro van aquí. Solo mover algo aquí cuando esté cerrado — sin posibilidad de cambio.

Ficheros sugeridos a crear a medida que avance el trabajo:

- `personajes.md` — perfiles de personaje finalizados (nombre, arco, querer/necesitar, dinámica de relación)
- `estructura.md` — estructura de capítulos/actos cerrada
- `mundo.md` — escenario, tono, reglas del mundo narrativo, época
- `temas.md` — los temas centrales del libro (no la trama — de qué trata el libro)

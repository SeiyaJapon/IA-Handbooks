# Commands

Named tasks the developer can invoke explicitly. Each command is a defined flow — not a skill the agent applies internally, but a workflow the developer activates by name.

Load a command's `index.md` when the developer invokes it or when the context makes it clearly relevant.

---

## Available Commands

| Command | When to use |
|---|---|
| `self-review` | Before opening a PR — structured review of your own diff |
| `contribute-memory` | Add a fact, convention, or gotcha to `memory/` in structured form |

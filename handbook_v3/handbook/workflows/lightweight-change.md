# Workflow: Lightweight Change

For trivial work — small, clear, reversible, low-risk.

## When to use

- Single file or small set of clearly related files
- The change is well-defined and the path is obvious
- Reversible without significant effort
- Does not affect architectural boundaries or contracts

## How to work

1. Act directly — no output record, no plan, no steps required
2. Report what changed when done
3. Flag anything unexpected that surfaced during the change

## What to skip

- Output records
- Plans
- Steps lists
- Collaboration mode question

## Escalate if

During execution you discover the change is broader than expected, affects contracts or shared code, or requires a decision that was not obvious from the original request. Stop, surface the finding, and reclassify.
